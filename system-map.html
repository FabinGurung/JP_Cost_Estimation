STATIC AUDIT · 2026-10-09

Which branch controls which website?

main — GitHub default / workflow owner

Preserves the original v0.1 homeowner estimator and runs the Pages publication workflow. Do not confuse a publishing trigger with the files served.

research/open-estimation-engine-v0.1 — research site source

The Pages workflow checks out this branch. Vercel Preview also builds from this branch, where the read-only CR-02 serverless API exists.

GitHub Pages — static

Serves HTML/CSS/JS and Known Rates/Finance navigation. It does not run Vercel's serverless /api/cr02-rates backend.

Vercel — research previews / main production

Vercel commit statuses may be successful even when current deployment HTTP status cannot be checked. Its team API was inaccessible at the last audit.

Privacy boundary: the Estimator website is public. Company payment amounts and private Drive workbook identifiers are deliberately not embedded. See Finance & Project Payments for an authorized navigation flow.

Why milestones, snapshots and archives differ

Milestone

A frozen, named checkpoint of a meaningful capability with supporting QA. It is not necessarily published to Production.

PRE / POST snapshot

Exact Git states on either side of a governed mutation; the rollback lineage is retained.

Archive_ alias

Commit-identical archived name for an older feature or snapshot. The source ref remains for audit until an authorized real rename is possible.

Current development

New work is appended on the research branch after a PRE snapshot, verified, then frozen at a new milestone when appropriate.
