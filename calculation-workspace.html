03 / EVIDENCE-FIRST COMPUTATIONS

Keep irregular field calculations flexible

Do not force every sketch, scribble, formula and revised quantity into a spreadsheet. Keep raw site evidence intact, work in a versioned calculation document, validate the measured item, then publish an approved projection.

Recommended: Quarto .qmd · Optional: Jupyter .ipynb

Read-only publication

Evidence to publication: four non-interchangeable states

  1. CAPTURED — source photograph or document retained in Drive; no quantity accepted
  2. WORKING_DRAFT — a .qmd/.ipynb explains computations, alternatives and deductions
  3. VERIFIED / APPROVED — source and revision checked; a reviewer admits selected measured items into the correct project register
  4. PUBLISHED — Actions validates a sanitized projection and Pages displays lineage and freshness; publication is not certification

Missing quantity remains null; never quietly substitute 0. Contractor claims, certified bills and recorded payments are distinct authorities.

Reusable document template

The public repository contains only a generic Quarto source template and metadata schema. Real project notebooks belong in appropriately restricted custody, not this public repo or Pages.

Safe source policy: source ID · organization/project/work item · revision · units · method · author/reviewer · evidence pointer · validation status · output hash. Original source data cannot be replaced by derived JSON.
