# M02 source derivations - iteration 001

Raw baseline: M02 / m02-raw-v1, commit 80a3650e8de3be1488b742f79246620543d2cffc. User authorized source-specific website derivations before semantic verification. The raw private corpus is preserved.

Six existing routes are populated separately. Kaski shows 973 reused district observations and 4,824 machine numeric candidates; the pipes catalogue shows 1,430 existing catalogue entries and 1,469 numeric candidates. Contractor, Users and DUDBC show 9,574 / 8,255 / 1,205 numeric candidates and all their page transcripts. Numeric roles, OCR descriptions and coefficients remain unverified; no estimator formulas consume these candidates.

Electrical quotation: 29 typed descriptions and 29 independently transcribed handwritten descriptions, distinguished as different document parts. All prices, quantities, customer fields, totals and full quote transcripts are withheld. This does not certify the handwritten wording or allocate new canonical rate IDs.

The UI supports source-local search, PDF-page filters, pagination, source evidence details and page-text view. All source text is inserted with textContent. Deterministic gzip JSON chunks load only for the chosen document/view and decompress in the browser. Modern browser DecompressionStream support is required. Missing numeric values remain null. SI/Imperial conversion is not inferred for unresolved source units.

Public projections include only selected presentation fields and public alias IDs. Original Drive IDs and private canonical source identities are excluded. The private archives retain full provenance. Public numeric-cell IDs allow deterministic reconciliation against the private corpus.

The existing v0.5.14 metadata inventory remains a historical checkpoint; v0.5.15 is loaded by the source explorer. No sources are merged or compared. Personal rates, MEP, company finance and the calculator remain unchanged.

Version control: milestone/m02-raw-extraction-20261012 remains frozen. This iteration lives on website/m02-iteration-001; future extraction corrections use extraction/m02-iteration-001 or a successor version. Production Pages continues to be owned by the main workflow, whose deployed product comes from the research branch.

Validation: JS syntax, original MEP/skeleton regressions and a source-derivation regression verify counts, per-source chunks, page coverage, stable IDs, privacy exclusions and preservation of 204 personal observations. A mobile browser visual inspection is not claimed. User visual feedback will guide iteration 002.
