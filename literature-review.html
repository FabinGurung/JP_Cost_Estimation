05 / RESEARCH & SOURCE PROVENANCE

Ten references behind the measurement and cost system

A targeted review of original standards and open technical documentation. Each source shows its recommended application and what it does not authorize. Reviewed 31 October 2026.

Research references · not project approvals

Method and boundaries

Selection criteria: primary issuing body, relevance to quantity takeoff, work pricing, billing or reproducible software, and an accessible public description. The list is ranked for this JP website—not a scored systematic literature review. For projects in Nepal, verify the applicable NBC, municipal requirements, contract and approved measurement rules before use.

How the literature changes our calculation workflow →

  1. LR-01 · Royal Institution of Chartered Surveyors (RICS)

    NRM 2 — Detailed measurement for building works

    October 2021; reissued as practice information October 2022

    Apply: Trade-specific measurement conventions, quantity rules, description and unit discipline

    Boundary: Not a Nepal statutory standard; project contract measurement rules and local codes prevail.

    Read original publication ↗
  2. LR-02 · Royal Institution of Chartered Surveyors (RICS)

    NRM 1 — Order of cost estimating and cost planning

    October 2021; reissued October 2022

    Apply: Separate early cost plans, element/group summaries, allowances, exclusions and AOC-like presentation

    Boundary: NRM grouping does not prescribe this project's approved tax or contingency amounts.

    Read original publication ↗
  3. LR-03 · AACE International

    Guide to Cost Estimate Classification Systems

    Professional Guidance Document No. 01; revision August 29, 2022

    Apply: Classify maturity of a price/estimate rather than presenting tentative assumptions as tender-ready

    Boundary: The exact AACE estimate class requires definition-maturity evidence, not arbitrary labels.

    Read original publication ↗
  4. LR-04 · buildingSMART International

    Industry Foundation Classes (IFC), version 4.3

    IFC 4.3.2.0; ISO 16739-1:2024

    Apply: Vendor-neutral model identifiers, geometry lineage and model-backed quantity evidence

    Boundary: IFC quantities require independent quantity/method validation before financial admission.

    Read original publication ↗
  5. LR-05 · IfcOpenShell open-source documentation

    IfcOpenShell cost and quantity schedule API

    API documentation; accessed 2026-10-31

    Apply: Interoperable BIM cost items, quantities, cost schedules and formulas; coordinate with JP CAD

    Boundary: Implementation reference, not itself an approved construction rate or design certification.

    Read original publication ↗
  6. LR-06 · Quarto / Posit open-source project

    Quarto — reproducible scientific and technical publishing

    Current online documentation; accessed 2026-10-31

    Apply: Preferred flexible .qmd format for irregular calculations, formulas, methods, illustrations and HTML/PDF outputs

    Boundary: Executable cells must be run only inside controlled workflows; never treat private notebooks as public site inputs.

    Read original publication ↗
  7. LR-07 · Project Jupyter

    The Jupyter Notebook Format (nbformat)

    nbformat 5.11 documentation; accessed 2026-10-31

    Apply: Alternative .ipynb format when exploratory calculations need narrative plus code and rich outputs

    Boundary: Notebook execution is not proof of source validity; clear sensitive outputs before publication.

    Read original publication ↗
  8. LR-08 · World Wide Web Consortium (W3C)

    PROV-O: The PROV Ontology

    W3C Recommendation, April 30, 2013

    Apply: Record source → calculation → validation → reviewer → publication provenance links

    Boundary: Use a small compatible provenance model; avoid adding unnecessary semantic-web infrastructure.

    Read original publication ↗
  9. LR-09 · Open Contracting Partnership

    Open Contracting Data Standard (OCDS)

    OCDS 1.1.5 documentation (reviewed 2026-10-31)

    Apply: Distinguish procurement, supplier/contractor award, contract changes, implementation and actual payments

    Boundary: Public-sector publication schema as a reference; does not authorize exposing private commercial transactions.

    Read original publication ↗
  10. LR-10 · GitHub Documentation

    Configuring GitHub Pages publishing with Actions

    Current online documentation; accessed 2026-10-31

    Apply: One validated static publication workflow and explicit visibility boundaries

    Boundary: Pages is static/public; not a secure edit interface or private source-data store.

    Read original publication ↗
