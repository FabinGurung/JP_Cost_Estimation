SI units are displayed from the original workbook. Choose Imperial for mathematically equivalent prices per foot, square foot, cubic foot or pound. Original source observations never change.

The list displays editorial short titles; tap one to read the full unabridged source description on the Work Specifications subpage. Units are displayed in human-readable notation (for example m³ rather than Cum, m² rather than Sqm, running m rather than Rm). Original SI values are extracted and never rewritten; Imperial display values are calculated from those SI prices, not new supplier quotations. Source formulas, original wording and coordinates remain in the private Drive archive. These are not the approved AEC Rate Master or CAD-verified quantities.

Categories and work types are editorial labels derived from the original work descriptions, not authoritative classifications. Compare source alternatives on the Rate Comparison page; hidden sheets are not assumed to be older or newer than visible sheets.
